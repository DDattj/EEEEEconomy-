현재 등록된 학습지 파일 관리

GitHub Pages로 무료 웹사이트 배포하기

이 대시보드 파일(index.html)과 공부한 학습지(.md) 파일들을 깃허브에 올리고 누구나 접속할 수 있는 웹 페이지로 공개하는 방법입니다.

1 GitHub Repository 생성

github.com 로그인 후 오른쪽 상단 + → New repository를 클릭합니다. 이름은 stock-study-archive로 지어줍니다.

2 index.html 및 .md 업로드

만들어진 저장소에서 uploading an existing file을 클릭하고, 지금 다운로드하신 이 메인 웹앱 파일(index.html)과 학습지 마크다운 파일들을 함께 드래그하여 올립니다.

3 GitHub Pages 활성화

저장소 Settings → Pages 메뉴로 이동하여 Branch를 main으로 바꾸고 Save를 누르면, 나만의 주식공부 주소가 생성됩니다!

아카이빙 꿀팁

새로운 학습지가 생길 때마다 [학습지 업로드] 메뉴에서 추가하고, 다운로드받은 마크다운 저장본을 깃허브 저장소에 커밋하면 나만의 멋진 주식 포트폴리오 잔디가 채워집니다.
